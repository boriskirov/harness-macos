# Harness-macos

Unofficial macOS menu-bar and dock app for Mistral Vibe (chat.mistral.ai) — Electron harness with persistent login, global hotkey (⌘⇧M), and recent-chats menu.

## Run

npm install && npm start

npx electron-builder --mac
